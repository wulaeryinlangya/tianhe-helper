# 三栏布局内容更新机制说明

## 📊 各栏位更新机制

### 左栏：天河政策新闻（📰）

**当前状态**：❌ 不会自动更新

- **数据来源**：`src/App.vue` 中的 `policyNews` ref（硬编码）
- **图片来源**：`public/news-thumbnails/` 目录下的静态文件
- **更新方式**：需要手动运行脚本或手动编辑代码

**如何更新**：
1. 手动方式：编辑 `src/App.vue` 中的 `policyNews` 数组
2. 自动截图：运行 `node scripts/capture-news-thumbnails.mjs`
3. 重新部署网站

**改进建议**：
- 方案 A：将新闻数据移到 `data/news.json`，类似政策数据的管理方式
- 方案 B：接入天河区政府 RSS/API（如果有的话）
- 方案 C：定期爬取官网新闻列表（需要后端服务）

---

### 中栏：主要内容区（📋）

**当前状态**：✅ 动态更新

- **表单页面**：用户输入时实时响应
- **政策列表**：基于用户画像和 `data/policies.json` 实时匹配
- **政策详情**：点击时动态加载
- **AI 问诊**：实时调用 API 生成内容

**更新触发**：
- 用户交互（填写表单、点击政策、搜索）
- `data/policies.json` 文件更新后刷新页面

---

### 右栏：申报截止提醒（📅）

**当前状态**：✅ 动态更新

- **数据来源**：从用户匹配的政策（`matchedPolicies`）中筛选
- **更新逻辑**：
  ```javascript
  upcomingDeadlines = computed(() => {
    // 从用户匹配的政策中筛选 30 天内截止的
    // 按剩余天数排序
    // 自动计算紧急程度（红/黄/绿）
  })
  ```
- **更新时机**：
  - 用户完成企业画像匹配后自动显示
  - 每次刷新页面时重新计算剩余天数

**注意**：
- 只显示**用户当前匹配到的政策**中即将截止的
- 如果用户没有匹配政策，会显示空状态
- 如果匹配的政策都没有明确截止日期，也显示空状态

---

## 💡 让左栏新闻也自动更新的方案

### 方案 1：简单方案 - 移到 JSON 文件

**步骤**：
1. 创建 `data/news.json`：
```json
[
  {
    "id": 1,
    "date": "2026-08-25",
    "title": "天河区发布2026年度科技创新扶持政策",
    "url": "http://www.thnet.gov.cn/",
    "thumbnail": "/news-thumbnails/news-1.svg",
    "summary": "天河区出台多项扶持政策，支持科技创新企业发展"
  }
]
```

2. 修改 `src/App.vue`：
```javascript
import newsData from '../data/news.json'
const policyNews = ref(newsData)
```

3. 更新新闻时：
   - 编辑 `data/news.json`
   - 运行截图脚本更新图片
   - 提交到 Git 并部署

**优点**：数据与代码分离，更新不需要改代码
**缺点**：仍需手动更新

---

### 方案 2：GitHub Actions 定时爬取

**步骤**：
1. 写一个爬虫脚本定期访问天河区政府网站
2. 使用 GitHub Actions 每天自动运行
3. 自动更新 `data/news.json` 和截图
4. 自动提交并触发 Vercel 重新部署

**优点**：完全自动化
**缺点**：需要维护爬虫，网站结构变化时需要调整

---

### 方案 3：接入 RSS/API（理想方案）

如果天河区政府网站提供 RSS 订阅或 API：
1. 在 Vercel Serverless 函数中获取最新新闻
2. 前端动态加载

**优点**：官方数据源，最可靠
**缺点**：需要官方支持

---

## 🎯 推荐方案

**短期**：使用方案 1（移到 JSON 文件）
- 成本低，易于维护
- 更新新闻时只需改 JSON 和运行截图脚本

**长期**：考虑方案 2（定时爬取）
- 如果新闻更新频繁，自动化更省力
- 需要评估维护成本
