# 天河政策通 - 三栏自动更新机制

## 概述

本文档说明左栏（政策新闻）、中栏（政策匹配）、右栏（申报日历）的数据更新机制。

---

## 左栏：政策新闻（自动更新）

### 数据源
- **文件**: `data/news.json`
- **内容**: 天河区政府网站最新政策新闻（标题、日期、链接、缩略图）

### 自动更新机制

#### 方式 1: GitHub Actions 定时爬取（已配置）
- **触发时间**: 每天北京时间 9:00（UTC 01:00）
- **工作流文件**: `.github/workflows/update-news.yml`
- **执行步骤**:
  1. 运行爬虫脚本 `scripts/update-news.mjs` 提取天河区政府网站最新新闻
  2. 运行截图脚本 `scripts/capture-news-thumbnails.mjs` 自动截取缩略图
  3. 如果有更新，自动提交到仓库
  4. Vercel 检测到代码变化后自动重新部署

**优点**: 
- ✅ 完全自动化，无需人工介入
- ✅ CI 环境已配置好 Chrome，截图稳定
- ✅ 真实网站截图，视觉效果最佳

**状态**: ✅ 已完成配置

#### 方式 2: 手动更新（备用）
如果需要立即更新，可以手动触发：
1. 访问 GitHub 仓库 Actions 页面
2. 选择 "自动更新政策新闻" workflow
3. 点击 "Run workflow" 按钮

## 中栏：政策匹配（实时计算）

### 数据源
- **文件**: `data/policies.json`
- **内容**: 天河区所有惠企政策详情

### 更新机制
- **类型**: 实时前端计算，基于用户输入的企业画像
- **逻辑**: 
  - 用户填写企业信息（行业、规模、营收等）
  - 前端根据 `policies.json` 实时匹配符合条件的政策
  - AI 问诊服务调用后端 API (`/api/chat`) 获取个性化建议

### 如何更新政策数据
**手动更新** `data/policies.json`:
1. 从天河区政府网站获取最新政策
2. 按照现有 JSON 格式添加/修改政策条目
3. 提交代码，Vercel 自动部署

**未来优化**:
- 可以开发后台管理系统，通过界面编辑政策
- 可以增加政策数据爬虫，自动同步官网更新

**状态**: 🔄 需手动维护（建议每季度更新一次）

---

## 右栏：申报截止提醒（实时计算）

### 数据源
- **来源**: 中栏已匹配的政策中的 `window.end`（申报截止日期）
- **逻辑**: 前端实时计算距离今天的剩余天数

### 更新机制
- **类型**: 完全自动，基于系统时间和已匹配政策
- **计算规则**:
  - 只显示 30 天内即将截止的政策
  - 按紧急程度排序（最紧急的在最上面）
  - 颜色编码：
    - 🔴 红色：≤ 7 天（紧急）
    - 🟡 黄色：8-15 天（注意）
    - 🟢 绿色：16-30 天（正常）

### 数据刷新
- **频率**: 每次页面加载时自动重新计算
- **依赖**: 中栏的政策数据（`policies.json`）

**状态**: ✅ 完全自动化，无需维护

## 故障排查

### 左栏新闻未更新
**可能原因**:
1. GitHub Actions 执行失败
2. 天河区政府网站结构变化，CSS 选择器失效
3. 网络问题导致爬虫无法访问

**解决方案**:
1. 查看 GitHub Actions 日志定位问题
2. 更新 `scripts/update-news.mjs` 中的 CSS 选择器
3. 手动触发 workflow 重试

### 右栏申报提醒为空
**可能原因**:
1. 当前确实没有 30 天内截止的政策（正常情况）
2. `policies.json` 中的政策缺少 `window.end` 字段

**解决方案**:
1. 检查 `data/policies.json`，确保政策包含 `window` 对象
2. 添加近期申报窗口的政策用于测试

### 中栏政策匹配不准确
**可能原因**:
1. 政策数据过时
2. 匹配逻辑需要优化

**解决方案**:
1. 更新 `data/policies.json`
2. 检查 `src/App.vue` 中的 `matchedPolicies` 计算逻辑
